# AGENTS.md

- This project is a data exploration playground for EDA with PDFs.
- There is no single objective beyond exploratory data analysis.
- Use Python for backend code.
- Use `uv` to manage Python dependencies.
- For frontend, TypeScript is fine.
- When scripts output to the console, use Python libraries from Textualize, such as `rich`, to make the output look polished and readable.
- Code should live in `./src`.
- Data files are in `./data`.
- User-authored Jupyter notebooks live in `./notebooks`; do not modify them unless explicitly asked.
